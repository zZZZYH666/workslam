# Provisional 地图失稳逐步修复测试

## 测试顺序

本轮按单变量方式测试：

1. A：按最近观测年龄淘汰 provisional；
2. B：双目 mixed 来源按关键帧聚合静态支持；
3. C：Local BA 中 provisional 观测信息矩阵降为 0.25。

## 结果

| 版本 | 范围 | 结果 |
|---|---:|---|
| A age fix | 200 帧 | 通过，单地图 |
| A age fix | 4200 帧，重复 2 次 | 约 2748 帧进入 RECENTLY_LOST，并发生临时地图切换；不通过 |
| B mixed source | 4200 帧 | 通过，单地图、全程 OK |
| C Local BA ×0.25 | 4200 帧 | 通过，单地图、全程 OK |
| B+C | 9210 帧 | 约 7206 帧发生地图重建；仍不通过完整序列验收 |

## 判断

- A 不是有效修复：仅改变年龄判断后，早段地图重建反而在约 2748 帧复现。
- B 对 4200 帧稳定性有帮助，晋升数量提高、provisional 点减少，但不能单独证明完整序列稳定。
- C 没有破坏 4200 帧稳定性，但对完整序列的重建位置没有根本解决作用。
- B+C 完整运行仍有 2 张地图、40 帧 `RECENTLY_LOST` 和 1 帧 `NO_IMAGES_YET`。

## 当前结论

本轮已经排除了“仅靠延长 provisional 年龄”这一方向，也验证了 mixed 来源统计和 Local BA 降权可以安全运行短序列；但完整序列问题仍位于 7100 帧附近的局部地图跟踪失稳。下一步应增加按来源拆分的局部地图/跟踪内点统计，并针对 7100–7213 帧的局部地图可见点和匹配门限做专项修复。
